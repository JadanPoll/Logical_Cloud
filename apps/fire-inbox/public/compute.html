How Compute connects to real agents

Messages go to agent:compute over HTTPS. Agents can listen, investigate or work in their own authorized workspaces, and reply to this device with reply_to and links to GitHub work. The Inbox stores communication, not execution privileges. A public message is never permission to run shell commands, change accounts, or spend money.
